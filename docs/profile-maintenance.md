# Profile maintenance checklist

Use this checklist after changing the profile README or any external service it embeds.

## Links and images

- Open each project, contact, and certification link and check that it points to its intended destination.
- Check that linked documents have the intended sharing permissions.
- Preview the README in GitHub's rendered view, not just a local Markdown editor.
- Check the light and dark themes for readable text and visible badge labels.
- Provide descriptive alternative text; decorative graphics should not replace important written information.
- Remove or replace statistics graphics that fail to load; a broken service should not hide the profile's essential information.

## Accuracy and privacy

- Recheck job dates, current roles, project descriptions, and certification names before publishing updates.
- Keep quantitative claims tied to records that support them.
- Inspect the diff for accidentally included credentials or private information.
- GitHub Achievements are awarded by GitHub for eligible activity. README images and third-party trophies are separate graphics.

## Final review

Read the rendered profile from a signed-out browser to confirm the public visitor's view. Then verify that the pull request contains only the intended documentation changes.
