# Maintaining this GitHub profile

This repository's README is displayed on the owner's GitHub profile.

## Making a change

1. Create a branch from the latest `main`.
2. Keep the change focused on one improvement: profile text, a verified link, an image, or maintenance documentation.
3. Preview Markdown before submitting a pull request.
4. Describe what changed and how it was checked.
5. Merge only the intended files after inspecting the diff.

## Content checks

- Use accurate role, education, and certification descriptions.
- Add project metrics only when they can be supported by evidence.
- Use HTTPS links and descriptive link labels.
- Provide meaningful alternative text for images and badges.
- Never publish access tokens, passwords, or private documents.
- Distinguish third-party README graphics from GitHub's earned Achievements.

See [the profile maintenance checklist](docs/profile-maintenance.md) for recurring checks.
